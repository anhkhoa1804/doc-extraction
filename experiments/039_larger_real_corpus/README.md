# Experiment 039 — larger real-corpus adequacy

039 asks whether an independent real-document corpus can provide enough
naturally occurring Mechanism-D activation, source-document diversity, and
role diversity for a defensible selective-policy study.

This experiment is a corpus and activation checkpoint.  It is not a policy
evaluation.  The production baseline is run only after the corpus, split,
identity exclusions, D2 definition, and activation-adequacy criterion are
frozen.  A positive count alone does not authorize policy design.

Raw images, source annotations, and baseline runs belong under the ignored
`results/` directory.  Compact manifests, audits, summaries, and reports are
tracked.

The intended terminal statuses are:

- `039_READY_FOR_POLICY_DESIGN`
- `039_BLOCKED_NO_DEVELOPMENT_ACTIVATION`
- `039_BLOCKED_INSUFFICIENT_DIVERSITY`
- `039_BLOCKED_CORPUS_INADEQUATE`
