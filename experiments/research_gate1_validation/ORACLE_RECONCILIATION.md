# Oracle-reconciliation upper bound

The baseline has 8/24 truth units with exact acquired text and unique accepted
ownership. One additional unit (`ind-13`) has exact text and multiple claims.
A deliberately liberal truth-informed feasibility oracle may choose one of its
existing claims, giving 9/24. The upper-bound gap is one truth unit: 4.2 points
over all truth units, or 11.1 points over the nine exact-text units.

This is not a true ownership oracle: truth names text and geometry, not a
canonical owner. It proves only that an existing claim could be selected, not
which claim is semantically correct. All nine exact-text units were already
canonical baseline duplicates, so the gap does not imply missing text or
quality improvement.

Conclusion: reconciliation ambiguity is observable, but available truth does
not support a meaningful causal reconciliation-gap estimate.
