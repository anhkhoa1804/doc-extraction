# Research Gate 1 — measurement validity

This bounded validation uses only completed Experiment 046 artifacts. It adds
no corpus, backend, capture point, routing rule, or recovery treatment.

The gate tests whether the surviving evidence-accounting framework has a
truth-side denominator and can localize real stage loss strongly enough to
justify a future multi-system study. The result is **GATE 1 FAILED**: the
framework remains useful engineering observability infrastructure, but the
available evidence does not make real loss-boundary attribution identifiable.

Primary analysis: `gate1_results_v2.json`. The earlier `gate1_results.json`
is retained as a pre-correction artifact; v2 corrects `ind-15` from presumed
OCR coverage failure to a truth-locator clipping mismatch.

The analysis is organized as:

* `TRUTH_SIDE_WATERFALL.md` — independent unit and measured states;
* `NO_OCR_DIAGNOSIS.md` — the five stored-v2 challenge no-centre cases;
* `FAULT_INJECTION.md` — functional, not causal, discrimination check;
* `ORACLE_RECONCILIATION.md` — the restricted upper-bound analysis;
* `CLAIM_LEDGER.md` — claim status and limits; and
* `RESULTS.md` — the final validity decision.
