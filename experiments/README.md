# Experiments

Each directory is one investigation. The numbering is chronological, not a
priority order.

```
NNN_short_name/
  README.md        what question this asks, and how to reproduce it
  config.yaml      the exact config the run used
  results.json     machine-readable results actually produced
  observations.md  what we concluded — and what we did not
```

**Only record experiments that were actually run.** An empty or missing
`results.json` means the experiment has not been executed yet; that is a
truthful state and is preferable to a placeholder. Do not populate example
numbers.

## Reproducing

Every experiment is reproducible from a clean checkout with the CPU config
and no GPU. See each `README.md` for the exact command. The general
sequence is in the root [README](../README.md) under "Local validation".

Raw run artifacts live in `outputs/` (gitignored, regenerated by the
commands here), not in this directory — these directories hold the
*question*, the *config*, and the *conclusion*, which are small and worth
committing.
