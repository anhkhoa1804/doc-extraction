# 042 analysis status

The 042 source-group-disjoint scout cohort has been acquired and independently
audited. The frozen 279-page population has not yet been processed by the
production pipeline, so there is still no observed production-role control
count, baseline invocation distribution, or role-normalization result.

The annotation-only scout found zero exact `document_index` annotations in the
279 selected pages. This is not evidence that the current Docling layout model
will emit zero `document_index` regions: DocLayNet's source vocabulary has no
such category, and the project does not define an automatic source-label to
`Region.label` conversion. A baseline replay is therefore justified to observe
the actual pre-treatment role and specialist provenance.

The immediate scientific objective is to discover whether natural
`document_index` regions exist outside all 038/039 source groups. A positive
scout count will not establish a selector; it will only make an independent
control population possible. A zero or concentrated count will be preserved
as a population failure.

The preregistered initial replay (one page per source group) completed 40/40.
It observed `PAGE_WIDE` on 34 pages and `LABELLED_CROP` on 6 pages, with no
`BOTH` or `NONE` pages. It emitted no natural `document_index` region in this
sample. This is a sample result, not a claim about the remaining 239 pages;
the full cohort replay remains necessary to estimate whether the independent
population can supply enough same-role controls.

No 039 held-out record is admitted or processed. No treatment is authorized.
